# karanratra.com

Personal portfolio and professional page of Karan Kumar Ratra — Senior Engineering Leader at Walmart Global Tech.

## What's here

- **Publications** — IEEE, ACM, and industry papers on distributed systems, cloud-native architecture, and AI automation
- **Open Source** — Curated GitHub repositories spanning Kafka ecosystems, cloud infrastructure, and data pipelines
- **Volunteering** — Mentor, judge, and speaker for HackMIT, HackHarvard, NASA Space Apps, and other globally recognized events
- **Memberships** — IEEE Senior Member, SCRS Distinguished Fellow, SAS Eminent Fellow, and more

## Running locally

Requires Ruby 3+ and Bundler.

```bash
bundle install
bundle exec jekyll serve --lsi
```
